# Where to Build Next

An interactive connectivity siting tool for Nigeria. It sorts every square kilometre by what it needs (served, slow, unmeasured town, rural coverage gap), ranks the communities to prioritise, and picks which registered health facilities should host new connectivity sites, either to reach the most people or the poorest first.

Oluwasola Oyinloye, DSN AI Bootcamp 2026, Geospatial Track.

Open the tool: https://dexsholex.github.io/where-to-build-next/

Data: Speedtest® by Ookla® Global Fixed and Mobile Network Performance Maps (mobile, Q4 2024), Meta population and Relative Wealth Index, GHSL degree of urbanisation, GRID3 health facilities, OCHA boundaries, and the Nigerian National Broadband Plan 2020-2025.
